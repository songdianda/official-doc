# official-doc

一个 [Claude Code](https://claude.com/claude-code) 技能（Skill），用于根据**党政机关公文格式国家标准（GB/T 9704—2012）**自动生成规范的 `.docx` 公文文件。

## 功能特性

- 自动排版：标题、主送机关、正文、附件说明、落款、页码等均按国标格式生成
- 编号检查：自动扫描并纠正公文结构层次编号错误（一、→（一）→ 1. →（1）→ ①）
- 支持从 `.docx` 文件提取内容并重新排版
- 内置方正小标宋简体、仿宋_GB2312、楷体_GB2312 字体

## 使用方式

### 作为 Claude Code Skill 使用

1. 将本项目克隆到本地：

```bash
git clone https://github.com/shuyu/official-doc.git
```

2. 在 Claude Code 中使用 `/official-doc` 命令，按提示提供公文内容即可生成规范公文。

### 直接运行示例脚本

```bash
pip install python-docx
python generate_gongwen.py
```

生成的文件将保存到桌面。

## 公文格式规范

| 元素 | 字体 | 字号 | 行距 |
|------|------|------|------|
| 标题 | 方正小标宋简体 | 二号（22磅） | 32磅 |
| 主送机关 | 仿宋_GB2312 | 三号（16磅） | 28磅 |
| 正文 | 仿宋_GB2312 | 三号（16磅） | 28磅 |
| 一级标题（一、） | 黑体 | 三号（16磅） | 28磅 |
| 二级标题（（一）） | 楷体_GB2312 | 三号（16磅） | 28磅 |
| 三/四/五级标题 | 仿宋_GB2312 加粗 | 三号（16磅） | 28磅 |
| 页码 | 宋体 | 四号（14磅） | — |

页面设置：A4 纸，上 37mm / 下 35mm / 左 28mm / 右 26mm。
