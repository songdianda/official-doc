# 党政机关公文格式规范（GB/T 9704-2012）

依据《党政机关公文格式》GB/T 9704-2012 及《党政机关公文处理工作条例》（中办发〔2012〕14号）。

## 0 字体说明（重要）

公文排版依赖以下字体，本技能包**不附带字体文件**（字体受著作权保护，需用户自行取得）：

| 用途 | 推荐字体 | 说明 |
|------|---------|------|
| 标题 | 方正小标宋简体 / 小标宋体 | 国标要求「2号小标宋体字」 |
| 正文、主送机关、附件说明 | 仿宋_GB2312 或 仿宋 | 国标要求「3号仿宋体字」 |
| 第二层标题 | 楷体_GB2312 或 楷体 | 国标要求「楷体字」 |
| 第一层标题 | 黑体 | 国标要求「黑体字」 |
| 页码 | 宋体 | 国标要求「4号半角宋体」 |

**python-docx 只能设置字体名称，不能嵌入字体文件。** 生成脚本内置字体回退链，会按「国标名 → 等效字体 → 通用兜底」逐项匹配本机已装字体，避免 Word 静默替换为默认字体。各系统实际字体名并不一致：

| 用途 | Windows 常见 | macOS 常见 | Linux 常见 |
|------|------------|-----------|-----------|
| 标题 | 方正小标宋简体 | （通常无小标宋，退到宋体类中宋） | 无，退到宋体 |
| 正文 | 仿宋_GB2312 / 仿宋 | 方正仿宋_GBK / 华文仿宋 | FangSong |
| 第二层 | 楷体_GB2312 / 楷体 | 楷体-简 / 华文楷体 | Kai |
| 第一层 | 黑体 | 黑体-简 / 华文黑体 | Hei / SimHei |
| 页码 | 宋体 | 宋体 / 宋体-简 | SimSun / Songti SC |

**注意**：字体缺失不会改变字号、行距、缩进、页边距等参数，但会改变字的外形。若标题被回退到普通宋体，仅影响观感，不影响合规性判定。

Windows 一般自带仿宋、楷体、黑体、宋体；「仿宋_GB2312」「楷体_GB2312」「方正小标宋简体」多数需单独安装（方正字体为商业字体，商用需取得授权）。

## 1 页面设置

| 项目 | 值 | 依据 |
|------|-----|------|
| 纸张 | A4 210mm × 297mm | 5.1 |
| 上白边（天头） | 37mm ± 1mm | 5.2.1 |
| 左白边（订口） | 28mm ± 1mm | 5.2.1 |
| 版心尺寸 | 156mm × 225mm | 5.2.1 |
| 下白边 | 35mm（由 297 − 37 − 225 推算） | 推算值 |
| 右白边 | 26mm（由 210 − 28 − 156 推算） | 推算值 |
| 每面行数 | 22 行 × 每行 28 字 | 5.2.3 |

## 2 标题

- 字体：**小标宋体（方正小标宋简体）**，字号 **二号（22磅）**
- 对齐：居中，可分一行或多行
- 行距：固定值 32 磅，段前段后 0
- 组成：「发文单位 + 关于 + 事由 + 文种」
- 回行要求：词意完整、排列对称、长短适宜、间距恰当；排列应为**梯形或菱形**，不得为上下等长的长方形或上下长中间短的沙漏形（7.3.1）

## 3 主送机关

- 编排于标题下空一行，**居左顶格**，回行仍顶格
- 最后一个机关名称后标**全角冒号**
- 字体：**仿宋_GB2312**，三号（16磅），行距固定值 28 磅
- 主送机关过多导致首页不能显示正文时，移至版记（7.3.2）

## 4 正文

- 字体：**仿宋_GB2312**，三号（16磅）
- **每个自然段左空二字**（首行缩进 2 字符），回行顶格
- 行距：固定值 28 磅，段前段后 0
- 公文首页必须显示正文（7.3.3）

### 4.1 结构层次序数

国标原文（7.3.3）：层次序数依次可用「一、」「（一）」「1.」「（1）」标注；**第一层用黑体字、第二层用楷体字、第三层和第四层用仿宋体字**。

实务中常用到第五层。本技能采用的字体规则：

| 层级 | 编号格式 | 字体 | 加粗 | 说明 |
|------|---------|------|------|------|
| 第一层 | `一、` | 黑体 | 否 | 国标明确 |
| 第二层 | `（一）` | 楷体_GB2312 | 否 | 国标明确 |
| 第三层 | `1.` | 仿宋_GB2312 | 是 | 国标未要求加粗，**加粗为通行做法** |
| 第四层 | `（1）` | 仿宋_GB2312 | 是 | 同上 |
| 第五层 | `①` | 仿宋_GB2312 | 是 | 国标未列第五层，**为实务扩展** |

- 第一、二层标题一般末尾不加标点符号，单独成段、不接内容

### 4.2 编号正文（非标题）

带编号但内容是工作事项的段落（如工作总结中「1. 完成了……，开展了……」），
**按正文排版、不加粗**，角色记为 `numbered_body`。

判断与处理详见 `paragraph-roles.md`。要点：
- 编号前缀相同不代表角色相同，`1.` 可能是 `heading3` 也可能是 `numbered_body`
- 拿不准按 `numbered_body` 处理并列出疑问
- 不得改写、补全、重排编号

## 4.3 附表

国标未对附表字号作强制规定。本技能采用的通行规格：

| 项目 | 值 |
|------|-----|
| 对齐 | 表格整体居中 |
| 边框 | 全线边框（`Table Grid`） |
| 字体 | 随正文用仿宋 |
| 表头字号 | 小四（12磅），**加粗** |
| 数据字号 | 五号（10.5磅） |
| 单元格 | 水平居中 + 垂直居中 |

- 附表数据必须与原文逐格一致，**不得改动任何数值**
- 位置：正文引用处之后，或文末（落款之后）
- 正文若已写明「（详见附表）」，可不再另加「附件：」说明

## 5 附件说明

- 正文下空一行，**左空二字**编排「附件」二字
- 后标**全角冒号**和附件名称；多个附件用阿拉伯数字标注顺序号（如「附件：1. XXXXX」）
- 附件名称后**不加标点符号**
- 名称较长需回行时，与上一行附件名称**首字对齐**（7.3.4）

## 6 发文机关署名与成文日期

- 正文（或附件说明）下空一行，**右空二字**编排发文机关署名
- 署名下一行编排成文日期，首字比署名首字**右移二字**
- 成文日期用阿拉伯数字将年、月、日标全，月、日不编虚位（7.3.5.2 / 7.3.5.4）
- 字体：仿宋_GB2312，三号（16磅），行距固定值 28 磅

## 7 页码

国标原文（7.5）：**4号半角宋体**阿拉伯数字，编排在版心下边缘之下，数字左右各放一条一字线；**一字线上距版心下边缘 7mm**。单页码居右空一字，双页码居左空一字。

| 项目 | 值 |
|------|-----|
| 字体 / 字号 | 宋体 / 四号（14磅） |
| 格式 | `— 1 —`（左右各一条一字线） |
| 一字线距版心下边缘 | **7mm**（国标原文口径） |
| Word 页脚换算值 | **4.58mm**（页脚底边距，叠加 4 号字半高后约等于 7mm） |

> 7mm 与 4.58mm 不矛盾：7mm 是**成品视觉规范**（一字线到版心下边缘），4.58mm 是 **Word 页脚位置设置值**。用 python-docx 时通过 `section.footer_distance` 设置 4.58mm 更接近实际效果。

### 7.1 三种页码样式（可选）

`page_number` 配置项控制页码样式，由使用者选择：

| 取值 | 效果 | 适用场景 |
|------|------|---------|
| **`center`**（默认） | 所有页页码**居中**，不区分奇偶页 | 单面打印、单位内行文、呈报稿；也是最不易出错的选择 |
| `odd_even` | 单页码居右空一字、双页码居左空一字 | 双面打印并装订成册，严格按 7.5 执行 |
| `none` | **不显示页码** | 单页文件、或有另行规定的版式 |

为什么不默认奇偶页：7.5 的左右错位是为**双面装订**设计的——翻开书时页码靠外侧才好看。单面打印或仅电子传阅时，页码忽左忽右反而显得凌乱；多数单位的日常行文、呈批件也并不按装订本排版。因此**默认居中**，需要装订成册时再显式选 `odd_even`。

- 版记页前有空白页的，空白页和版记页不编排页码
- 附件与正文一起装订时，页码连续编排
- 选 `odd_even` 时若只取到单页页脚，脚本会降级为仅奇数页显示并保留页码
